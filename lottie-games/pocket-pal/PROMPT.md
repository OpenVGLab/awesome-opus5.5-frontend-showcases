你负责独立完成一款浏览器小游戏《口袋宠物 POCKET PAL》：照顾一只小宠物长大的养成游戏，玩法借鉴电子宠物，角色、名字和美术全部原创。画面里的一切图形都用 Lottie 动画做。

【交付】
- 交付目录里的 index.html 加若干 Lottie 动画文件（assets/*.json，Bodymovin 格式）；播放器用 lottie-web，浏览器通过 HTTP 打开 index.html 就能玩，不引用任何外网资源。
- 画面里的所有图形元素——宠物、食物和玩具、房间背景、特效、按钮和面板——都必须是 Lottie 动画，只用形状图层，不用图片和字体图层；HTML/CSS 只负责布局和文字（数值、菜单文案、说明），不能用 CSS、Canvas 或手写 SVG 画图形来代替。
- 游戏逻辑用 JavaScript，按玩家操作和宠物状态用 lottie-web 的 playSegments、goToAndStop、setSpeed、setDirection 等切换动画片段。宠物每个成长阶段至少有待机、开心、吃东西、玩耍、洗澡、困倦、睡觉、生病、闹脾气 9 个动作片段。
- 页面按 16:9 画面居中缩放，窗口变化时画面完整不变形。
- 界面文字用中文，标题配英文副标题。音效和背景音乐用 Web Audio 实时合成，第一次交互后开始发声，M 键静音。
- 所有 Lottie 文件都能被 lottie-web 单独正常播放，合计不超过 2 MB。
- 只借鉴玩法，不使用原作的角色、名字或标志性素材。

【玩法】
- 从一颗会晃动的蛋开始，点几下孵出小宠物，给它起名字。宠物有四项需求：饱食、心情、清洁、体力，随时间下降（游戏内 1 天 = 现实 4 分钟）。
- 照顾方式：喂食（三种食物，各补不同数值，吃多了会撑）；玩耍（一个 30 秒小游戏：宠物左右移动接住落下的星星，接到越多心情涨得越多）；洗澡（用鼠标搓出泡泡，泡泡越多越干净）；关灯睡觉（房间切到夜晚，体力恢复）。
- 需求长期过低会生病或闹脾气，这时要先治疗或哄好；偶尔会有随机事件（门口出现礼物、窗外下雨、宠物做噩梦）。
- 照顾得好积累成长值：幼年 → 少年 → 成年，三个阶段外形不同；照顾方式不同，成年后的样子也不同（至少两种）。养到成年后显示结局。
- 难度：轻松（需求下降慢）、普通、硬核（下降快，会饿病）；用 localStorage 存档，重新打开页面时按离开的时间结算需求变化。

【操作】鼠标或触屏点击按钮和物品；洗澡时按住拖动搓泡泡；小游戏里 ← → / A D 或拖动控制宠物；P 暂停，H 帮助，M 静音。

【画面】
- 温暖的小房间：木地板、窗户（外面有白天、黄昏、夜晚和雨天）、小床、食盆和玩具箱；柔和的暖色调，圆润可爱。
- 宠物是圆滚滚的原创小生物，表情丰富，眨眼、呼吸、四处张望这些细节一直在动；需求低时表情和动作会明显变化。
- 特效：喂食时食物飞入、爱心冒出、泡泡升起和破裂、升阶段时的闪光变身。
- 四项需求用带图标的进度条显示；底部一排动作按钮（带悬停和按下动画），右上角有暂停和静音按钮。

【流程与界面】
- 标题页：继续存档或新游戏、难度选择、帮助。
- 帮助页：四项需求和各种照顾方式的说明。
- 暂停菜单有继续、重新开始、返回标题；成年结局页展示宠物最终形态、养育天数和照顾统计，可以重新养一只。

【验收】
在无头 Chrome 里自动试玩：从标题页开始新游戏，孵蛋，完成喂食、玩一局小游戏、洗澡、睡觉各一次，再用测试钩子加速时间，确认需求下降、生病和成长阶段切换都能触发。要求 0 个 JS 报错、所有 Lottie 文件都成功加载、帧率不低于 55 fps；在 1280×720 和 1920×1080 两种分辨率下截图，确认画面完整、文字不溢出。
