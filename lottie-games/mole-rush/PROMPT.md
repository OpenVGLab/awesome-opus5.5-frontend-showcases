你负责独立完成一款浏览器小游戏《萌鼠出洞 MOLE RUSH》：限时反应游戏，玩法借鉴打地鼠，角色、名字和美术全部原创。画面里的一切图形都用 Lottie 动画做。

【交付】
- 交付目录里的 index.html 加若干 Lottie 动画文件（assets/*.json，Bodymovin 格式）；播放器用 lottie-web，浏览器通过 HTTP 打开 index.html 就能玩，不引用任何外网资源。
- 画面里的所有图形元素——地鼠和其他角色、洞口、锤子、特效、背景、按钮和面板——都必须是 Lottie 动画，只用形状图层，不用图片和字体图层；HTML/CSS 只负责布局和文字（分数、时间、菜单文案、说明），不能用 CSS、Canvas 或手写 SVG 画图形来代替。
- 游戏逻辑用 JavaScript，按玩家操作用 lottie-web 的 playSegments、goToAndStop、setSpeed、setDirection 等切换动画片段。每种地鼠至少有探头、张望/挑衅、被敲中、缩回 4 个动作片段；锤子有挥下和回弹片段。
- 页面按 16:9 画面居中缩放，窗口变化时画面完整不变形。
- 界面文字用中文，标题配英文副标题。音效和背景音乐用 Web Audio 实时合成，第一次交互后开始发声，M 键静音。
- 所有 Lottie 文件都能被 lottie-web 单独正常播放，合计不超过 2 MB。
- 只借鉴玩法，不使用原作的角色、名字或标志性素材。

【玩法】
- 草地上 3×3 九个洞，地鼠随机探头又缩回，趁它露头时敲中得分；每局 60 秒。
- 角色：普通地鼠（1 分）；戴头盔的地鼠（要敲两下，3 分）；金色地鼠（出现时间很短，10 分，还会加 3 秒）；抱着炸弹的刺猬（不能敲，敲了扣分并震屏）；冰晶花（敲中后 5 秒内所有地鼠变慢）。
- 连续敲中不失手累积连击，分数倍率随连击上升；连击到 10 进入“狂热”状态，背景变色，地鼠出得更快、分数翻倍，失手即结束狂热。敲空洞口算失手。
- 节奏随时间加快，最后 10 秒有倒计时提示。
- 难度：简单（出洞慢、刺猬少）、普通、困难（出洞快、同时冒出多只、刺猬多）；用 localStorage 分难度记录最高分，结算按分数给 1～3 颗星。

【操作】鼠标或触屏点击洞口挥锤；键盘用小键盘 1～9，或 Q W E / A S D / Z X C 对应九个洞；P 暂停，H 帮助，M 静音。

【画面】
- 阳光明媚的卡通菜园：远处的风车和篱笆、会随风摆动的向日葵和胡萝卜叶，九个洞口带泥土边缘。
- 地鼠圆头圆脑、表情夸张：探头时东张西望，被敲中时眼冒金星、脑袋上鼓包；头盔、金色光泽、刺猬的炸弹引线这些区别一眼能看出来。
- 锤子是一把跟随鼠标的大木槌，点击时挥下并回弹；特效有敲击星星、尘土、金币迸出、冰冻雪花、狂热状态的背景光效。
- HUD：分数、剩余时间（带动画的计时器）、连击数和倍率，右上角有暂停和静音按钮（按钮本身也是带按下动画的 Lottie）。

【流程与界面】
- 标题页：难度选择、开始、帮助、各难度最高分，背景里地鼠在自动探头。
- 帮助页：操作说明和每种角色的动画图示及分值。
- 开局有 3、2、1 倒计时；暂停菜单有继续、重新开始、返回标题；结算页显示分数、星级、命中率、最高连击和各角色敲中次数，破纪录时有庆祝动画，可以再来一局。

【验收】
在无头 Chrome 里自动试玩：从标题页开局，实际敲中和敲空若干次，触发一次连击和一次敲到刺猬，打完一整局看到结算页。要求 0 个 JS 报错、所有 Lottie 文件都成功加载、帧率不低于 55 fps；在 1280×720 和 1920×1080 两种分辨率下截图，确认画面完整、文字不溢出。
