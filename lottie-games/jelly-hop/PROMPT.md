你负责独立完成一款浏览器小游戏《果冻跳跳 JELLY HOP》：按住蓄力、松开起跳的平台跳跃，玩法借鉴《跳一跳》，角色、名字和美术全部原创。画面里的一切图形都用 Lottie 动画做。

【交付】
- 交付目录里的 index.html 加若干 Lottie 动画文件（assets/*.json，Bodymovin 格式）；播放器用 lottie-web，浏览器通过 HTTP 打开 index.html 就能玩，不引用任何外网资源。
- 画面里的所有图形元素——角色、平台、道具、特效、背景、按钮和面板——都必须是 Lottie 动画，只用形状图层，不用图片和字体图层；HTML/CSS 只负责布局和文字（分数、菜单文案、说明），不能用 CSS、Canvas 或手写 SVG 画图形来代替。
- 游戏逻辑用 JavaScript，按玩家操作用 lottie-web 的 playSegments、goToAndStop、setSpeed、setDirection 等切换动画片段。角色至少有待机、蓄力、起跳、空中、落地、完美落地、跌落 7 个动作片段。
- 页面按 16:9 画面居中缩放，窗口变化时画面完整不变形。
- 界面文字用中文，标题配英文副标题。音效和背景音乐用 Web Audio 实时合成，第一次交互后开始发声，M 键静音。
- 所有 Lottie 文件都能被 lottie-web 单独正常播放，合计不超过 2 MB。
- 只借鉴玩法，不使用原作的角色、名字或标志性素材。

【玩法】
- 主角是一团圆滚滚的果冻，站在一块平台上。按住蓄力时果冻被压扁、身体发颤，蓄力越久跳得越远；松开后果冻弹起，按抛物线落向下一块平台。
- 落在平台上得 1 分；落在平台正中心算“完美”，得 2 分并连击加倍（2、4、8……封顶 32），平台上泛起一圈光环；落空就跌下去，本局结束。
- 平台形状、大小、间距随机变化，越往后越小越远。特殊平台：弹簧垫（落上后自动小跳一次）、慢慢塌掉的饼干、左右移动的托盘、放着金币的蛋糕（落上加分）。
- 镜头随果冻平滑推进，远景分层视差移动。
- 难度：简单（平台大、间距小）、普通、困难（平台小、会移动的多）；用 localStorage 分难度记录最高分。

【操作】按住空格 / 鼠标 / 触屏蓄力，松开起跳；P 暂停，H 帮助，M 静音。

【画面】
- 糖果甜点世界：奶油色天空、马卡龙色的甜点平台（杯子蛋糕、布丁、饼干、糖果盒），远景是棉花糖山和缓缓飘动的云。
- 果冻半透明、有高光，蓄力时挤扁、起跳时拉长、落地时回弹（挤压与伸展），跌落时有惊慌表情。
- 特效：起跳时的灰尘、完美落地的光环和星星、连击时逐级变大的数字背景、金币闪光。
- HUD：分数、连击倍率、最高分，右上角有暂停和静音按钮（按钮本身也是带按下动画的 Lottie）。

【流程与界面】
- 标题页：难度选择、开始、帮助、各难度最高分，背景里果冻在自动演示。
- 帮助页：操作说明和几种特殊平台的动画图示。
- 暂停菜单有继续、重新开始、返回标题；结算页显示本局分数、最高连击、完美次数，破纪录时有庆祝动画，可以再来一局。

【验收】
在无头 Chrome 里自动试玩：从标题页开局，实际蓄力起跳若干次（包括成功落地和跌落各至少一次）。要求 0 个 JS 报错、所有 Lottie 文件都成功加载、帧率不低于 55 fps；在 1280×720 和 1920×1080 两种分辨率下截图，确认画面完整、文字不溢出。
