什么是潮汐 SDK

潮汐 SDK 是一套轻量的实时消息客户端，帮助你在几分钟内为产品接入聊天、通知与多人协作。这里是中文占位文字，用来展示正文段落在文档站中的排版、行高与字重层次。

  • 毫秒级送达

    全球 30+ 边缘节点就近接入，端到端延迟通常低于 100ms。

  • 断线不丢消息

    自动重连并补发离线期间的消息，历史记录默认保留 7 天。

  • 多端一套 API

    Web、iOS、Android 与小程序共用同一套接口与事件模型。

适用场景 在线客服 直播弹幕 协同编辑 订单通知 IoT 设备上报

常见问题

共 3 个问题
01 如何获取 appId 和密钥？

登录潮汐控制台，进入「应用管理」并点击「新建应用」，创建完成后即可在应用详情页看到 appId。密钥只用于服务端签名，请不要写进前端代码或提交到代码仓库。

02 网络断开后，消息会丢失吗？

不会。SDK 默认开启自动重连（reconnect: true），恢复连接后会按顺序补发离线期间的消息；超过 7 天的历史消息，可以通过服务端接口分页拉取。

03 支持哪些平台和浏览器？

支持 Chrome、Edge、Safari、Firefox 的最近两个大版本，以及 iOS 13+、Android 8+ 和微信、支付宝小程序。服务端推荐使用 Node.js 18 及以上版本。
