FAQ

常见问题

什么是 Case？

Case 就是一道评测题：一段 prompt，加上你关心的评判要点。把同一个 Case 交给不同模型作答，结果在擂台上并排展示，谁强谁弱一目了然。

「本地 API Key」是什么意思？

你使用自己在模型服务商处申请的 API Key。Key 只保存在你的本地环境中，调用模型时直接使用你自己的额度。

贡献徽章怎么获得？

Pro 用户把自己编写的 Case 分享到社区题库，就会获得贡献徽章，展示在个人资料上。

Team 的共享题库和协作标注怎么用？

团队成员共用同一套 Case 题库，评测口径保持一致；多人还可以对同一批模型输出打分、写标注，结果汇总在一起。

可以先用 Free，之后再升级吗？

当然可以。Free 无需付费就能体验 3 个内置 Case；需要更多 Case 或团队协作时，再升级到 Pro 或 Team。
